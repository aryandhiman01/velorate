Velorate

Production-ready Rate Limiter for Modern Applications

Fast • Flexible • Distributed • Type Safe

Vision

Velorate is a reusable backend infrastructure library that protects APIs against abuse, brute-force attacks and excessive traffic while supporting multiple storage engines and algorithms.

Goals

  • Framework agnostic core
  • Express, Next.js and NestJS adapters
  • Memory + Redis storage
  • Multiple algorithms
  • TypeScript first
  • Production ready

Request Workflow

Incoming Request
      │
Identify Client (IP/User/API Key)
      │
Load Configuration
      │
Read Counter from Store
      │
Run Selected Algorithm
      │
Allowed?
 ├── Yes → Update Counter → Next()
 └── No  → HTTP 429

Algorithms

  • Fixed Window – easiest implementation.
  • Sliding Window – smoother request distribution.
  • Sliding Log – stores timestamps for accuracy.
  • Token Bucket – production favourite.
  • Leaky Bucket – steady request flow.
