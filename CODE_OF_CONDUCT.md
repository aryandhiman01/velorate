# Code of Conduct

Velorate aims to provide a respectful and professional environment for everyone contributing to the project.

This Code of Conduct applies to all interactions within the repository, including issues, pull requests, discussions, and code reviews.

---

# Expected Behavior

Contributors are expected to:

- Be respectful and professional.
- Provide constructive feedback.
- Be open to technical discussions and code reviews.
- Respect different opinions and approaches.
- Focus discussions on improving the project.

---

# Unacceptable Behavior

The following behavior is not acceptable:

- Personal attacks or harassment.
- Discrimination of any kind.
- Offensive or abusive language.
- Trolling or intentionally disruptive behavior.
- Spam or irrelevant content.
- Sharing private or confidential information without permission.

---

# Maintainer Responsibilities

Project maintainers are responsible for:

- Reviewing contributions fairly.
- Keeping discussions respectful.
- Enforcing this Code of Conduct when necessary.
- Making decisions that are in the best interest of the project.

Maintainers may edit, remove, or reject contributions that violate these guidelines.

---

# Reporting Issues

If you encounter behavior that violates this Code of Conduct, please open a private discussion with the project maintainer.

Reports should include enough information to understand the issue.

All reports will be reviewed fairly and handled appropriately.

---

# Scope

This Code of Conduct applies to all project-related interactions, including:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Code Reviews

---

# Enforcement

Violations of this Code of Conduct may result in actions including:

- Requesting changes to behavior.
- Removing inappropriate content.
- Closing discussions or issues.
- Rejecting pull requests.
- Restricting future contributions for repeated or serious violations.

Enforcement decisions are made at the discretion of the project maintainers.

---

# Changes

This document may be updated as Velorate evolves.

Contributors are encouraged to review the latest version before contributing.

---

Thank you for helping make Velorate a professional and collaborative open-source project.
