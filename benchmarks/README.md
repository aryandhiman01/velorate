# Velorate Benchmarks

This directory contains the official benchmark suite for Velorate.

The goal is to compare Velorate against other popular Node.js rate limiting libraries under identical workloads.

## Libraries

- Velorate
- express-rate-limit
- rate-limiter-flexible

## Metrics

- Requests/sec
- Average Latency
- P95
- P99
- Throughput
- Memory Usage

All benchmarks are executed using Autocannon under the same runtime configuration.
